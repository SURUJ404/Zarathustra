CLI Documentation

Every command in the Astra toolchain.

Command Description
prove compile Compile a .zara file into a constraint system (R1CS)
prove witness Execute the compiled program with given inputs to compute a witness
prove setup Generate proving key and verification key from a compiled program
prove generate Generate a zero-knowledge proof from compiled program + witness + proving key
prove verify Verify a proof against a verification key
audit circuit Scan circuits for security vulnerabilities
audit solidity Scan Solidity verifier contracts for vulnerabilities
deploy verifier Export a Solidity verifier contract from a verification key

Command Reference

prove compile

▾

Description

Compiles a .zara source file into a flattened R1CS constraint system using the Groth16 backend.

Usage

$ astra prove compile -i program.zara --curve bn128

Options

  • -i, --input — Path to the .zara source file
  • --curve — Target curve: bn128, bls12_381, bls12_377, pallas (default: bn128)

Example

$ astra prove compile -i program.zara --curve bn128
Compiled code written to 'out'
Number of constraints: 2

prove witness

▾

Description

Executes the compiled program with provided inputs to compute a valid witness for proof generation.

Usage

$ astra prove witness -i out --stdin <<< '["42"]'

Options

  • -i, --input — Path to compiled binary
  • --stdin — Read JSON arguments from stdin
  • --output — Path to write witness (default: witness)

prove setup

▾

Description

Generates a proving key and verification key from a compiled constraint system.

Usage

$ astra prove setup -i out

prove generate

▾

Description

Generates a zero-knowledge proof using a compiled program, witness, and proving key.

Usage

$ astra prove generate -i out -w witness -p proving.key

prove verify

▾

Description

Verifies a proof against a verification key.

Usage

$ astra prove verify -v verification.key -j proof.json

audit circuit

▾

Description

Scans circuit files for common security vulnerabilities such as under-constrained signals, missing assertions, and potential information leaks.

Usage

$ astra audit circuit -i program.zara

audit solidity

▾

Description

Audits Solidity verifier contracts for insecure patterns, gas inefficiencies, and known vulnerability signatures.

Usage

$ astra audit solidity -i verifier.sol

deploy verifier

▾

Description

Exports a Solidity verifier contract from a verification key, ready to deploy on Ethereum.

Usage

$ astra deploy verifier -i verification.key
