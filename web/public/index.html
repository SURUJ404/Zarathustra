See It In Action

Prove that you know x, y such that x + y == sum — without revealing x and y.

📄 sum.zarazara
// Prove you know x, y such that x + y == sum
def main(field public sum,
         field private x,
         field private y) -> field {
    assert(x + y == sum);
    return 1;
}

Everything You Need

What the toolkit actually ships today.

📝

Zara DSL

Imperative, typed, assert-based circuit language with span-aware diagnostics and an LSP hook.

🔐

Honest Groth16

Real ark-groth16 proving over BLS12-381. verify() loads vk.json + proof.json and checks the bound public inputs — tampering is rejected.

🧩

Backend Registry

Plugin-style backends behind one trait: ark-groth16 (default) and a hand-rolled legacy reference implementation.

📚

Standard Library

Versioned gadgets including Poseidon hashing and Merkle trees with inclusion proofs.

🛡️

Security Scanner

Static analyzers: signal-flow analysis for unconstrained public inputs plus CEI/reentrancy checks for Solidity.

📤

Verifier Publishing

JSON test vectors from real artifacts today; EVM export that honestly refuses non-BN254 curves rather than emitting a fake contract.

🌐

Web IDE + CLI

Browser-based Monaco playground backed by the same engine, or the astra CLI in your terminal.

⚡

Rust Native

Blazing fast compilation and proving powered by Rust with the arkworks cryptography stack.
