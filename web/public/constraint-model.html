Witness convention

Index layout

All rows are indexed over the witness vector w[0..n]:

OrderNamePublic/PrivateValue
0~onepublic (implicit)1
1..main paramsper declarationinput values
thenStmt::Declareprivateinit value or 0
then~mult_<k>privatel * r (postfix order)
  • num_public starts at 1 (the implicit ~one at index 0).
  • num_private counts every witness index past the public block.
  • Params are allocated in program order; private-marked params become private, all others public.

Total compile cost for a straight-line circuit of m constraints over at most n active vars is O(m·n); a linear-definition circuit (one LC term per var) stays at O(m).

Per-construct encoding

The oracle

Addition — a + b

No row. Returns the merged LC: terms of a and b summed at matching indices; zero terms dropped.

Subtraction — a − b

No row. Returns the merged LC: terms of a and −b.

Multiplication — a * b

Emits exactly one row A·B = C:

new private var idx = next var (named ~mult_<k>, k = #rows so far)
witness[idx]      = eval(a) · eval(b)
row.k:  A = lc(a),  B = lc(b),  C = [(idx, 1)]

Ground truth witness check: w[idx] == eval(a) * eval(b).

Assert equal — l == r

Emits exactly one row 1 · (l − r) = 0:

A = [(0, 1)]        // ~one
B = lc(l) − lc(r)
C = []              // empty

Ground truth: w[l] − w[r] = 0.

Declare — field t = <init>

Fresh private var with the init value (or 0 if unspecified):

idx = next var
witness[idx] = eval(init)   // 0 if no init

if — if (c) { body }

Condition evaluated and its LC discarded; body always lowered. Ground truth: num_constraints(if) equals body constraints; the condition adds no row.

return — no-op

Emits nothing.

Soundness

Collision resistance

Every private ~mult_<k> and declare variable is uniquely indexed. The R1CS encoding a · b = c binds multiplicative gate outputs, and 1 · (x − y) = 0 binds equality.

The index assignment is deterministic: the same program string + same input values produce bit-for-bit identical witness and (A,B,C) triples across compiles — this is the invariance fuzzing checks. Distinct program semantics (different DAGs) must produce distinct constraint/witness artifacts.

Worked example

Example B — mul

def main(field public c, field private a, field private b) -> field {
    field t = a * b;    // Declare -> ~mult_0 row
    assert(t == c);     // Constrain row
    return 1;           // no-op
}

Witness: [~one, c, a, b, t, ~mult_0] → num_variables = 6, num_private = 4, num_constraints = 2.

row 0: A=[(2,1)] B=[(3,1)] C=[(5,1)]    // a·b = ~mult_0
row 1: A=[(0,1)] B=[(4,1),(1,−1)] C=[]   // t − c = 0

Any change to this layout (index order, term ordering, count) is a ground truth violation — fuzzers and reviewers check exactly these invariants.
